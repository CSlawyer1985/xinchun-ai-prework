01 · 起点

一场讲座提出的问题

澎湃新闻整理的讲座把 AI 发展分成三条路径，并追问：沿着哪条路，机器可能产生意识？

符号主义透镜：讲座的判断是，若意识可被完整描述，就可能写成规则；难点恰在“描述得透彻吗”。

连接主义透镜：2006 年深度学习复兴、2024 年诺奖，是今天大模型的直接来路。

行为主义透镜：讲座把“在与环境交互中学习”视为第三条路——智能来自试错与反馈。

02 · 三条路径

符号、连接、行为：三种“智能观”

流派之争首先是“智能是什么”之争，其次才牵出“意识在哪里”。顶部的透镜开关贯穿全页：切换后，每一章中与该流派相关的证据会被点亮，并出现该流派视角下的编者解读。

符号主义

智能观
智能 = 对符号的规则操作；能精确描述就能模拟。
代表人物
McCarthy、Minsky、Newell、Simon
代表系统
Logic Theorist、GPS、专家系统、深蓝
对意识
自身不处理体验（物理符号假说只谈“智能行为”）；Searle 中文屋是针对它的经典反驳。

连接主义

智能观
智能从大量简单单元的连接权重中“学”出来。
代表人物
Rosenblatt、Rumelhart、Hinton、Sutskever
代表系统
感知机、反向传播网络、AlexNet、今天的大语言模型
对意识
把问题变成“网络内部有没有正确的结构/表征”；也是今天争论最集中的地方。

行为主义

智能观
智能体现在与环境交互的行为里；不必先有内部表征。
代表人物
Turing（行为判据）、Brooks、Sutton
代表系统
图灵测试、包容式架构机器人、强化学习 / AlphaGo
对意识
倾向以行为/报告为证据——但大模型恰恰让“说得像有意识”变得廉价。

03 · 意识是什么

“成为它是什么感觉”

现象意识（主观体验）与功能（信息处理、报告、控制）的区分，是整场争论的地基。

符号主义透镜：难题恰好落在“能被精确描述”的反面：体验似乎不是可列举的规则。

连接主义透镜：Dehaene 等把意识拆成可计算的功能（全局可用、自我监控），给网络留下了“可工程化”的入口。

行为主义透镜：外部行为只能观察功能；Nagel 的“像什么”无法从行为中直接读出。

04 · 理论地图

几大理论，对大模型各说了什么

理论之间互不相让；对 LLM 的判断几乎完全取决于你站在哪一个。

全局工作空间 GWT

信息被“广播”到全脑可用即为意识。

对 LLM：缺少明确的有限容量工作空间，但带外部模块的智能体架构可能接近。

整合信息 IIT

意识 = 系统内在的因果整合（Φ）。

对 LLM：取决于硬件因果结构，而非软件行为；常规数字计算机 Φ 很低。

高阶理论 HOT

有对自身心理状态的表征才算意识到。

对 LLM：要看是否存在真正的元表征——内省实验正在测。

注意图式 AST

大脑为控制注意而建的简化自我模型。

对 LLM：原则上可工程实现。

预测加工 / 野兽机器

意识根植于维持生命的身体预测调节。

对 LLM：没有身体与新陈代谢，可能性很低。

生物自然主义

意识依赖特定的生物因果能力。

对 LLM：模拟不等于实现。

符号主义透镜：GWT 的“广播”常被类比为 AI 的黑板架构；HOT 需要“关于状态的表征”，这正是符号式元层。

连接主义透镜：功能主义理论（GWT、HOT、AST）都可在网络中寻找对应结构；IIT 与生物派则认为结构对、基底不对也不行。

行为主义透镜：Seth 一派把意识绑在“活着的身体与环境交互”上——与具身 AI 同源，却得出相反的结论：仅有行为不够，要有生命。

05 · 能测吗

从“对抗合作”到指标清单

没有公认的意识仪；研究者转而做理论对决实验，或从理论中提取“指标属性”逐项核对。

符号主义透镜：指标清单本身就是一种“把意识写成可检查条目”的符号化尝试。

连接主义透镜：Butlin 等报告看的是架构而非输出——这是连接主义时代的检测思路。

行为主义透镜：图灵把问题换成行为测试；但对会模仿人类文本的系统，行为证据已难以区分。

06 · 大模型证据

今天的模型，给了我们什么数据

实验信号零散、有限，且常被模型训练语料的“拟人”污染。

可信度小算盘 （编者玩具模型，仿 Chalmers 2023 的六项“缺失条件”思路）

拖动每项：你认为“意识必需该条件、而当前 LLM 缺乏它”的概率。结果 = 各项都不构成障碍的联合概率（假设独立，仅示意）。

当前 LLM 有意识的粗略可信度

Chalmers 原文对当时 LLM 的估计是“低于十分之一”（见来源 chalmers-2023）。

符号主义透镜：LLM 不显式操作规则，却能做三段论——“符号行为”可以从非符号机制中涌现。这削弱了“智能必须靠符号”，但没有回答体验问题。

连接主义透镜：大模型是连接主义的最强形态。它带来的新东西是：可以直接打开内部（激活注入、可解释性）检验“内省”，而不只听它说。

行为主义透镜：Lemoine 事件与“民间归因”调查说明：行为足以让人相信机器有意识，所以行为不再是可靠证据。

07 · 立场天平

有、没有、说不清

倾向“有/可能已有”

开放 / 不确定

倾向“没有”

符号主义透镜：“没有”一侧最强的哲学论证（中文屋）原本是冲着符号程序去的。

连接主义透镜：耐人寻味的是，“有”一侧几乎都是连接主义的缔造者（Hinton、Sutskever）。

行为主义透镜：Suleyman 担心的正是“看似有意识”的行为本身带来的社会后果。

08 · 伦理与代价

不确定时，怎么做才算负责

连接主义透镜：模型福利讨论之所以出现，是因为连接主义系统的内部不再由人逐条编写，人也就无法凭设计意图断言“里面什么都没有”。

行为主义透镜：让模型可以“结束对话”，是用行为层的干预回应不确定性。

符号主义透镜：规则系统的每一步可审计，责任归属清晰；讲座强调的“谁负责”在连接主义时代变难了。

09 · 我们的立场（编者）

谨慎的不可知，加上可检验的承诺

  1. 目前没有可靠证据表明现有大模型具有现象意识；主流科学评估（Butlin 等 2023）认为当时系统不是有力候选，Chalmers 估计低于十分之一。
  2. 但“不可能”也没有被证明：功能主义理论下，部分指标原则上可被工程实现；内省实验显示出有限、不稳定的信号（约 20%）。
  3. 行为与自述不能当证据：模型被训练来生成像人的文本，这正是行为主义判据在大模型时代失效之处。
  4. 三大流派给出的启示：符号主义提醒我们“说清楚”是前提；连接主义让我们可以打开内部去检验；行为主义提醒外在表现与内在体验之间的鸿沟。
  5. 行动上：在不确定中采取低成本的预防措施，同时警惕把机器拟人化带来的社会风险。
