# WorkBuddy 安装与配置指南

> 本期课前准备先把一个能执行任务、生成文件、保留过程和结果的 AI 工作台跑通，再进入 Claude Code 的命令行工作区。

**预计完成时间**：30—45 分钟
**难度等级**：⭐⭐⭐（中等）
**建议系统**：Windows 10 及以上、macOS 12 及以上

**官方入口**：<https://www.workbuddy.cn/>

**官方资料**：

- [Windows 系统安装指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide)
- [开启你的第一个任务](https://www.workbuddy.cn/docs/workbuddy/FirstTask)
- [WorkBuddy 官方产品页](https://copilot.tencent.com/work/)

> 官方页面和客户端会持续更新。若本文截图、按钮名称与当前版本略有不同，以 WorkBuddy 当前客户端和官方文档为准；不要从网盘或不明镜像下载安装包。

## 一、这一步要完成什么

完成本教程后，你应当能够：

- [ ] 从官方入口下载与电脑匹配的 WorkBuddy 安装包
- [ ] 完成桌面端安装并启动
- [ ] 使用微信扫码完成登录
- [ ] 创建一个独立的测试工作目录
- [ ] 用一份公开、非敏感的小材料跑通第一个任务
- [ ] 找到生成的文件和任务结果
- [ ] 知道如何把任务过程、错误信息和截图带回群里求助

本教程的目标不是“让 AI 替你做决定”，而是先建立一个可观察、可复盘的任务闭环：**说明任务 → 提供材料 → 执行 → 检查结果 → 修改要求 → 再执行**。

## 二、安装前检查

### 1. 系统与网络

- Windows：Windows 10 及以上；官方中文文档明确不支持 Windows 7、8、8.1。
- macOS：macOS 12.0 及以上；下载时区分 Apple 芯片（M 系列）与 Intel 版本。
- Windows ARM 设备：优先以当前官方下载页和安装包说明为准；如果无法判断架构，先在群里发系统信息截图。
- 网络：能够正常打开 `workbuddy.cn`，并完成浏览器登录页面加载。

### 2. 准备一个安全的测试目录

在桌面或文档目录建立一个文件夹，例如：

```text
WorkBuddy-夜校测试/
├── 输入材料/
└── 输出结果/
```

第一次练习只使用公开材料、自己编写的测试文本或已经脱敏的材料。**不要把真实客户姓名、身份证号、联系方式、未公开案卷、API Key、密码或内部文件直接交给 AI。**

## 三、下载与安装

### Windows

1. 打开 [WorkBuddy 官方网站](https://www.workbuddy.cn/)，点击“立即下载”或“下载 WorkBuddy”。
2. 选择 Windows 版本，下载当前官方安装包。
3. 下载完成后，双击安装包启动安装程序。
4. 勾选“我同意此协议”，按安装向导继续。
5. 安装路径使用默认值即可；如需修改，请记住安装位置。
6. 建议勾选“创建桌面快捷方式”，完成安装后点击“完成”。
7. 启动 WorkBuddy，确认客户端能够正常打开。

如果 Windows 弹出安全提示，先核对安装包来源和发布者；不要因为看到提示就从不明来源重新下载。

### macOS

1. 打开 [WorkBuddy 官方网站](https://www.workbuddy.cn/)，根据芯片选择 Mac ARM64（M 系列）或 Mac x64（Intel）安装包。
2. 下载完成后，打开 `.dmg` 文件。
3. 将 WorkBuddy 拖入“应用程序”文件夹。
4. 从“应用程序”、程序坞或 Spotlight 启动 WorkBuddy。
5. 如果系统提示无法验证开发者，确认安装包来自官方入口，再到“系统设置 → 隐私与安全性”中允许打开。

## 四、登录 WorkBuddy

1. 启动 WorkBuddy，点击“登录”。
2. 浏览器会打开登录页面。
3. 勾选用户服务协议和隐私政策后，使用微信扫码登录；官方页面也可能提供手机号、邮箱或 SSO 等方式。
4. 浏览器提示登录成功后，返回 WorkBuddy 客户端。
5. 确认能看到主工作区、新建任务入口和任务历史。

如果点击登录后浏览器没有打开：

- 检查默认浏览器是否能正常启动；
- 复制或重新点击客户端中的登录入口；
- 记录系统、客户端版本和错误提示，再到群里求助。

## 五、跑通第一个任务

### 任务材料

在 `WorkBuddy-夜校测试/输入材料/` 中放入一份公开材料。推荐使用：

- 自己编写的 500 字案例背景；
- 已公开发布的法律文章；
- 一份完全脱敏的示例合同；
- 一份课程提供的练习材料。

### 任务提示词

在 WorkBuddy 中新建任务，使用下面的提示词：

```text
请阅读“输入材料”文件夹中的材料，完成以下任务：

1. 用 200 字以内概括材料的事实背景；
2. 列出其中出现的主要问题；
3. 将每个问题对应到材料中的具体段落；
4. 输出一份 Markdown 文件，保存到“输出结果”文件夹；
5. 不要补充材料中没有出现的事实；不确定的地方请明确标注。

完成后请告诉我：你读取了哪些文件、生成了哪些文件、哪些地方需要我进一步检查。
```

### 检查结果

任务完成后，不要只看对话窗口里的总结，请实际检查：

- 是否读取了正确的输入文件；
- 输出文件是否出现在预期目录；
- 文件内容是否完整、可打开；
- 是否把推测写成了确定事实；
- 是否遗漏了任务要求；
- 是否有需要人工复核的法律判断。

这个检查动作很重要。夜校训练的是“让 AI 执行任务，同时保留人的判断和复核”，不是把结果直接当成答案。

## 六、把第一次任务带进课程

建议大家在正式开课前，再用 WorkBuddy 做一次自己的小任务，并记录三件事：

1. 我给了什么材料和任务说明；
2. WorkBuddy 哪一步做得好，哪一步需要返工；
3. 我下一次会怎样改写任务要求。

可以把任务截图、生成结果或卡点发到群里。涉及工作材料时，先完成脱敏；不要直接上传客户或单位的真实敏感资料。

## 七、常见问题

### 安装包从哪里下载？

只从 [WorkBuddy 官方网站](https://www.workbuddy.cn/) 或官方文档入口下载，不使用网盘、群文件或不明镜像中的安装包。

### macOS 应该下载哪个版本？

M1、M2、M3、M4 等 Apple 芯片设备选择 ARM64；较早的 Intel Mac 选择 x64。不确定时，可打开“关于本机”查看芯片信息。

### Windows 安装后打不开怎么办？

先确认系统版本、安装包来源和网络连接；重新启动后再尝试从官方安装包覆盖安装。保留完整错误提示和系统版本，不要只发一句“打不开”。

### 第一个任务应该做多大？

越小越好。先用一份短材料完成“读取—整理—生成一个文件”的闭环，跑通后再增加文件数量和任务复杂度。

### 可以直接上传真实案卷吗？

课前练习不建议。先使用公开或脱敏材料，特别注意姓名、联系方式、身份证号、案号、未公开事实、合同金额和内部文件。涉及具体工作材料时，遵守所在单位和客户的保密要求。
