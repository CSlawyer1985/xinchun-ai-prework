# 四明山法师 AI 夜校 · 课前准备总览

**四明山法师 AI 夜校：先导课 + 6 节主课 + 返场复盘 + 社群陪跑**

这是一门面向法律从业者的进阶型 AI 实战课。课程主线围绕模型与工具能力、工作流能力、数据与算力判断力展开，强调实操、场景与可落地，目标不是“听懂概念”，而是让你真正把 AI 放进自己的工作里。

---

## 📋 课程机制（重要）

### 1. 学费 + 保证金机制

- 本课程采用申请制筛选，问卷仅作意向摸底与后续定向邀请依据
- 基础学费为 `888` 元；录取入班后需另行预交保证金 `1000` 元
- 海泰所律师学费全免，仅需缴纳保证金
- 设保证金是为了帮助大家形成学习约束：认真听课、认真做作业、积极互动
- 全勤并按要求完成课程，可获得电子结业证书并全额退还保证金

### 2. 课程节奏（固定）

- 原则上每周一堂，具体时间以后续通知为准
- 每次上课后给你**一整周**做练习和作业，用于消化吸收
- 主课共**6次**，并配套 1 节先导课与 1 节返场课
- 全程配套社群陪跑

### 3. 课程结构（1+6+1）

- **先导课 × 1**：对齐预期、说明规则、锁定最低准备标准、收集真实法律场景
- **主课 × 6**：Day 1 工作台、Day 2 Claude Code 基础、Day 3 Claude Code 进阶、Day 4 工具链与法律工作流、Day 5 算力与模型路由、Day 6 数据专题
- **返场课 × 1**：作业复盘、案例点评、嘉宾分享、后续行动建议
- **社群陪跑**：每节主课后提交作业、群内反馈、暴露卡点、持续推进

### 4. 激励与约束机制

- 全勤并按要求完成课程：电子结业证书 + 全额退还保证金
- 优秀学员：罚没保证金作为本期优秀学员奖金发放，并可成为下一期助教（免学费）
- 缺课、缺作业：保证金罚没
- 连续 2 次未完成作业：课程组有权劝退
- 录取后需签署《学习承诺书》

### 5. 互动共学机制

- 我们鼓励分享真实法律场景中的问题和作业
- 课程目标之一是寻找同频法律人，形成长期共学网络

## 🔑 账号准备

### 必须准备的账号（至少2类）

**1. 国内模型账号（至少1个）**

- 候选：智谱GLM / Kimi / DeepSeek
- 用途：保证中国大陆网络环境下可稳定直连
- 建议：先开通一个主力账号，充值小额测试预算

**2. 国际模型账号（至少1个）**

- 候选：OpenAI（ChatGPT）/ Anthropic（Claude）/ Google（Gemini）
- 用途：对比能力边界，覆盖高质量写作和复杂推理场景
- 注意：多数情况下需要VPN或企业合规出口网络

**✅ 建议最低组合：1个国内可直连 + 1个国际模型备用。**

### 计费与接入限制（务必先看）

- 高频使用（连续写作、长时协作）优先评估 `Coding Plan`（订阅）
- 低频或波动任务优先 `PAYG`（按量计费），并设置月度预算上限
- 不同平台存在调用速率、并发、模型白名单等限制，开课前先完成一次真实调用测试
- 国际平台可能有地区/手机号/支付方式限制，请预留注册和验证时间

## 🆘 获取帮助的方式

### 第一层：查阅文档

- **问题类型**：安装失败、配置错误、命令不识别等
- **解决方法**：查阅《04_常见问题FAQ.md》

### 第二层：微信群求助

- **问题类型**：文档中没有覆盖的问题、需要人工判断的问题
- **解决方法**：在学员微信群中提问
- **提问技巧**：
  - 描述你在做什么步骤
  - 截图显示错误信息
  - 说明你的操作系统（Windows/Mac/Linux）

### 第三层：截图求助AI（终局建议方案，也是你应该养成的习惯）

- **问题类型**：文档和微信群都无法解决的问题
- **解决方法**：将错误截图发给网页版AI，寻求解决方案
- **推荐工具**：
  - 网页版Claude：https://claude.ai/
  - 网页版ChatGPT：https://chat.openai.com/
  - KIMI：https://www.kimi.com/
- **提示词模板**：
  ```
  我在安装[工具名称]时遇到了错误，请帮我分析原因并提供解决方案。

  我的操作系统：[Windows 10/Mac macOS 13/Ubuntu 20.04]
  我在执行的步骤：[简述你正在做什么]
  错误信息：[粘贴错误信息或截图描述]

  请提供详细的解决步骤，谢谢！
  ```

**⚠️ 注意**：

- 截图时请包含完整的错误信息（不要只截一半），如果是命令行代码，可以直接复制代码内容提供
- 不要泄露敏感信息（如API Key、密码等）
- 提问时请尽量详细，这样AI才能更准确地帮助你
