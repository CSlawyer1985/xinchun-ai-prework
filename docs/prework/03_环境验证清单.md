# 环境验证清单

**预计完成时间**：10—15 分钟
**目的**：确认 WorkBuddy、ChatGPT / Codex CLI 与 Claude Code 三条入口至少各完成一次最小验证。

**前置要求**：

- [ ] 已完成《01_WorkBuddy_安装与配置指南.md》
- [ ] 已完成《02_Claude_Code_安装与配置指南.md》
- [ ] 已完成《02_ChatGPT_CLI与GUI_安装指南.md》（如参加 ChatGPT / Codex 练习）

## 一、WorkBuddy 验证

- [ ] 已从官方入口下载安装并启动 WorkBuddy
- [ ] 已完成浏览器或微信扫码登录
- [ ] 能看到新建任务入口
- [ ] 在独立测试目录中完成了一个小任务
- [ ] 能找到生成的文件或任务产物
- [ ] 已人工检查输出，没有把 AI 结果直接当作结论

推荐最小任务：读取公开或脱敏文本，提取三个关键事实，生成一份 Markdown 摘要并保存到输出文件夹。

## 二、ChatGPT 桌面端与 Codex CLI 验证（可选）

### ChatGPT 桌面端

- [ ] 已从 <https://chatgpt.com/download/> 安装官方桌面端
- [ ] 已登录 ChatGPT 账号
- [ ] 能完成一次对话或 Work 小练习
- [ ] 知道 ChatGPT、Work 和 Codex 入口的区别

### Codex CLI

```bash
npm install -g @openai/codex
codex --version
codex --login
```

- [ ] `codex --version` 能返回版本号
- [ ] 已使用 ChatGPT 账号完成登录
- [ ] 在独立测试目录中完成一次需要确认的本地任务
- [ ] 默认使用需要确认的审批方式，没有直接开启全自动模式

## 三、Claude Code 验证

### 1. 基础安装

```bash
claude --version
claude doctor
```

- [ ] `claude --version` 能返回版本号
- [ ] `claude doctor` 没有未处理的关键错误
- [ ] 已完成浏览器登录或课程组指定的组织 / 网关登录
- [ ] 能在测试目录中启动 `claude`

### 2. 本地文件任务

- [ ] Claude Code 能读取测试目录中的公开或脱敏文本
- [ ] 能根据要求生成一个新文件
- [ ] 生成文件位于预期目录
- [ ] 我能说明 Claude Code 读取、修改或生成了哪些文件

## 四、课程前安全检查

- [ ] 测试材料已脱敏，或本身就是公开材料
- [ ] 没有在截图、提示词或日志中暴露 API Key、密码、手机号和内部链接
- [ ] 我知道 AI 生成结果需要人工检查
- [ ] 我知道遇到问题时要提供系统、工具、步骤和完整错误信息
- [ ] 我预留了正式开课前的练习时间

## 五、遇到问题怎么办

1. 回到对应教程，确认是否漏做某一步；
2. 查看《04_常见问题 FAQ》；
3. 在群里发送操作系统、工具版本、正在执行的步骤、完整错误信息和截图；
4. 截图前遮盖 API Key、密码、手机号、邮箱和内部材料；
5. 不要只说“打不开”或“报错了”，尽量说明你希望完成什么。

## 六、完成确认

- [ ] WorkBuddy 已登录，并完成一个可检查的小任务
- [ ] Claude Code 已启动，并能返回模型回复
- [ ] ChatGPT 桌面端与 Codex CLI 已完成安装和登录（如参加该入口练习）
- [ ] 三类工具都只在测试目录中处理公开或脱敏材料
- [ ] 我已完成人工复核，并记录了自己的第一个卡点

完成后，你已经具备进入先导课的最低准备条件。遇到个别问题不必停在原地，带着完整记录进入群内交流即可。
