## 四个章节

- **CLI 命令**——终端启动与子命令（`claude -p`、`claude -r`、`claude mcp`、`claude config` …）
- **斜杠命令**——会话内操作（`/init`、`/clear`、`/compact`、`/model`、`/resume` …，含近百条）
- **内置工具**——Claude 的手脚（Bash、Read、Edit、Grep、Task、WebFetch …）
- **配置 / 权限 / 钩子**——`settings.json`、hooks、permissions 的关键键名

每条命令都配说明、示例、运行效果；右侧常驻"命令详解"面板，敲对一条即揭示"何时用 / 实战贴士 / 别名"。

## 怎么用

1. 打开练习后，从左侧栏选一个章节，逐字敲出当前命令。
2. 敲对自动进下一条（揭示卡停留约 2 秒，空格可跳过）；敲错则当前字符红字保持到改正。
3. 顶部可切深色模式、开关按键音效；侧栏底部有"错题本"和"重置本章进度"。
4. 进度保存在浏览器本地（localStorage），换章节、关页面都不丢，下次打开接着练。

## 适合谁

- 刚装好 Claude Code、想尽快形成肌肉记忆的学员。
- 用过一阵但总记不住 `/compact`、`/rewind`、`claude -r` 这类高频命令的人。
- 课后想随手刷两道、保持手感——每次 5 分钟，把命令刻进手指。
