# 实用工具总览

这部分会持续补充课程中高频使用、值得收藏的工具资料。

## 当前已收录

- [01 Claude Code 速查表](/tools/01_Claude_Code_速查表)：把常用快捷键、Slash 命令、CLI 参数、配置项集中到一页，方便开课时随查随用。
- [02 Claude Code 提示词 324 条中文翻译版](/tools/02_Claude_Code_提示词_324条_中文翻译版)：适合课后查阅的 PDF 资料，补充常见提示词模板与任务表达方式。
- [03 法律概念 WIKI](https://cslawyer1985.github.io/legalwiki/index.html)：基于 Karpathy LLM Wiki 方法论的实践示例，基于LLM快速构建面向法律学习与实务检索的概念词条库。
- [04 Claude for Legal中国法适配](https://cslawyer1985.github.io/claude-for-legal-ZH/)：面向中国法律人的 Claude 使用指南，涵盖法律场景下的提示词技巧与实操案例。
- [05 法律 Agent 运行结构仪表盘](/tools/05_法律Agent运行结构仪表盘)：78 个交互知识节点，拆透法律 Agent 的完整运行结构——从看懂到会用、会改、会沉淀。
- [06 Claude Code 命令打字练习](/tools/06_Claude_Code_命令打字练习)：把 100+ 条命令练成肌肉记忆——逐字敲击、敲对进阶、错题本回看，进度本地保存。

## 建议使用方式

1. 第一次接触工具时先通读一遍，知道能力边界。
2. 上课实操时保持页面常开，遇到忘记的命令直接回查。
3. 课后把你最常用的几项整理进自己的笔记或 `CLAUDE.md`。
