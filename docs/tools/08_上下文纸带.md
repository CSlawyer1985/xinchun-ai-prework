## 这是什么

一个讲解**上下文管理**的交互式教学实验：把对话画成一条会生长的纸带，规则、消息、Skill、MCP 返回、子 Agent 结果……每一段来源都看得见，token 计数用内嵌 gpt-tokenizer（cl100k_base）真实切分。

## 三种玩法

- **跟着看**：6 个基础实验，按「下一步」逐段观察纸带如何生长，「播放演示」自动接续。
- **亲手试**：打开模拟 Agent，输入消息、点快捷问题或「加入上下文」，触发可见的意图摘要与教学模拟回复。
- **追踪 Agent**：进入「Agent 全流程」，连续经历规则 → Skill → 文件筛选 → SQL → MCP → 子 Agent → Team → Hook → 压缩，点分支按钮查看不同 Agent 各自的纸带。

## 能回答的问题

- 上下文窗口是什么？token 怎么算？窗口装不下时「截取历史」和「改用摘要」有什么区别？
- Skill、MCP、子 Agent、Team、Hook 各自在什么时刻、把什么装进哪条纸带？
- 卷动、折叠为什么只改变显示、不清除上下文？
- 为什么换任务时常常要「新建对话」？旧信息什么时候又有用？

## 边界说明

- 文本分词是真实的，但未计角色封装、隐藏服务提示等开销，不代表真实 API 完整用量；图片、音频、视频显示的是教学说明片段。
- 各组件加载方式因宿主而异，本页展示一种常见且可追踪的工作流，不是全平台统一协议。
- 无关历史按素材话题标签计算，是教学标记，不是对真实模型注意力或准确率的测量。
